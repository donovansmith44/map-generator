# Excluded historical background (MAPS-X2)

## Source decision and scope

The removed `aourednik/historical-basemaps` vendor carried GNU GPL version 3 in `data/historical-basemaps/LICENSE` at **cf3c348**. The owner's permissive-only rule excludes it and descendants, irrespective of their labels or biblical identities. The twelve source snapshots, adapter, compiler ingest and time-aware slug shadows are removed. This removes a drawing, never a people, polity, identity, Scripture statement or alternative reading. Unlocated extents stay recorded and undrawn; plain land means Unrecorded, never evidence that nobody held it.

Inventory base **cf3c348** includes X0 **7bcbaba**. `tools/historical_basemaps_inventory.py --check` reproduces this table from that base, the vendored ten-era table and exact old atlas-polity shadow spans. These inherited dates explain the old output; they are not new chronology decisions. Actual permitted replacements consume the adopted stop/date and holding evidence.

Rows replay the old 0.02° snap and named-feature admission, then subtract only the old polity id/name slug shadow spans. A listed outline survives for at least one year in that era; `suppressed` lists ones hidden for the entire overlapping interval. Feature references `index:Xp/Yr` identify zero-based source features and their admitted polygon/ring counts, so an outline is reproducible without retaining its vertices. Anonymous features were never drawn.

## Lineage and golden consequences

The X0 catalogue now includes original raw, 1e-7° quantized and old 0.02°-snapped GPL feature vertex sets, with file checksums and source-feature indices. The real compiler checks repository GeoJSON and custom vendored polity inputs before transformation; all timeline/partition admissions and accumulated output borders use the same exclusion door. Renaming, ring rotation/reversal, split files, multiple border records and content-preserving derivations retain the complete exclusion refusal. Fingerprints are irreversible evidence, not redistributed geometry. Coordinate-changing ancestry beyond the recorded transforms still requires C4's general typed source/derivation admission; no fingerprint claim can substitute for that.

Expected golden change: all surviving GPL background fills, borders and names in the era table disappear at both existing cameras, while retained independently evidenced layers remain. Removed slug shadows also stop inserting polity-start/end moments into the background layer. Exact changed `(stop, camera, probe)` samples require a freshly valid canon; no golden has been re-blessed. Gate results and blockers are recorded in the X2 report.

## Decisions and alternatives

- Remove every GPL snapshot and both raw-state ingest and slug-based suppression. Identity is resolved only by X4's explicit registry, never by equal display-name slugs.
- Leave missing ownership/course evidence Unrecorded. Rejected alternatives: retaining GPL under a different source name, tracing its drawings, importing a different copyleft atlas, inventing a hull/constant, or silently treating missing holdings as Unclaimed.
- Reuse the existing X0 SHA-256 exclusion door, serde_json and Proptest. The inventory uses installed Pyclipper 1.4.0 (MIT; Clipper engine Boost Software License 1.0) for box intersection and validity, instead of hand-written polygon logic; Python json/hashlib/subprocess are standard-library tools. No new application parser, package, schema or shared geography type is introduced.
